# Навчально-методичний комплекс освітнього компонента<br>«Прикладні алгоритми кіберфізичних систем»


## 1 ПРИЗНАЧЕННЯ ТА ЗАГАЛЬНИЙ ОПИС РЕПОЗИТОРІЮ

Цей репозиторій містить повний дидактичний та інженерно-методичний комплекс освітнього компонента **«Прикладні алгоритми кіберфізичних систем»** для здобувачів вищої освіти першого (бакалаврського) рівня спеціальності **F7 «Комп'ютерна інженерія»** (галузь знань **F «Інформаційні технології»**).

Метою комплексу є надання здобувачам та викладачам єдиної структурованої інформаційної платформи, яка забезпечує наскрізний цикл підготовки: від вивчення формальних моделей обчислень на рівні **Brainware** до практичної розробки, симуляції, мережевого оркестрування та контейнеризації розподілених кіберфізичних систем (КФС).

## 3 СКРІЗНИЙ ТЕХНОЛОГІЧНИЙ СТЕК

У процесі виконання лабораторних, практичних робіт та розрахунково-графічного проєкту здобувачі опановують інструментарій, що відповідає сучасним вимогам до розробників у галузі Embedded Systems, IIoT та Edge/Fog Computing:

| Категорія | Використовуване програмне забезпечення та інструменти |
| :--- | :--- |
| **Мікроконтролерне середовище** | Arduino IDE (v1.8.x / 2.x — компіляція C/C++ скетчів `.ino`), схемотехнічний симулятор SimulIDE (v0.4.15+), ATmega328P |
| **Серверні платформи та скрипти** | Node.js (v18.0+ / v20.0+), Python (v3.10+), JavaScript (ECMAScript 2022+) |
| **Оркестрація та візуалізація** | Node-RED (v3.1+), плагін `node-red-dashboard` |
| **Мережева інфраструктура** | MQTT-брокер Eclipse Mosquitto (v2.0+), WebSockets |
| **Контейнеризація** | Docker Engine (v24.0+), Docker Compose (v2.20+), мережі `bridge`, іменовані томи `volumes` |
| **Бази даних** | InfluxDB (v2.7+) або PostgreSQL (v15+) |
| **Аналітика та графічна формалізація** | Python (`pandas`, `numpy`, `matplotlib`), Mermaid.js, PlantUML, Diagrams.net (Draw.io) |

## 4. КРОКОВИЙ ГАЙД З РОЗГОРТАННЯ ЛОКАЛЬНОГО РОБОЧОГО СЕРЕДОВИЩА

Для виконання всіх практичних та лабораторних завдань освітнього компонента здобувачу необхідно налаштувати базовий інструментальний стек на локальному комп'ютері.

### Крок 1. Встановлення Node.js та Node-RED
1. Завантажте та встановіть версію **Node.js LTS** з офіційного сайту [nodejs.org](https://nodejs.org/).
2. Перевірте встановлення у терміналі:
   ```bash
   node -v
   npm -v
   ```
3. Встановіть глобально платформу **Node-RED** з [nodered.org](https://nodered.org/) та CLI-інструмент візуалізації Mermaid:
   ```bash
   npm install -g --unsafe-perm node-red @mermaid-js/mermaid-cli
   ```
4. Для встановлення дашборду візуалізації у Node-RED виконайте:
   ```bash
   cd ~/.node-red
   npm install node-red-dashboard
   ```

### Крок 2. Встановлення середовища Python
1. Встановіть **Python 3.10+** з офіційного сайту [python.org](https://www.python.org/).
2. Встановіть необхідні аналітичні бібліотеки за допомогою менеджеру пакетів `pip`:
   ```bash
   pip install numpy pandas matplotlib
   ```

### Крок 3. Налаштування Docker та Docker Compose
1. Встановіть **Docker Desktop** з офіційного сайту [docker.com](https://www.docker.com/) (Windows/macOS) або **Docker Engine + Docker Compose** (Linux).
2. Перевірте функціонування демона контейнеризації:
   ```bash
   docker -v
   docker compose version
   ```

### Крок 4. Налаштування середовища Arduino IDE
1. Завантажте та встановіть **Arduino IDE** з офіційного сайту [arduino.cc](https://www.arduino.cc/en/software).
2. Середовище використовується для написання, компіляції скетчів C/C++ (`.ino`) та експорту скомпільованого двійкового файлу прошивки (**Sketch -> Export Compiled Binary** / `Ctrl + Alt + S`), що створює готовий `.hex` файл у папці проєкту.

### Крок 5. Налаштування схемотехнічного симулятора SimulIDE
1. Завантажте та розархівуйте схемотехнічний симулятор **SimulIDE** з офіційного сайту [simulide.com](https://www.simulide.com/).
2. Інсталяція не потрібна; запуск здійснюється через виконуваний файл `SimulIDE.exe` (Windows) або системний бінарник у Linux.
3. Симулятор використовується для створення віртуальної схеми на базі мікроконтролера ATmega328P (Arduino Uno), завантаження прошивки `.hex` (контекстне меню -> *Load firmware*) та моніторингу виведення даних у послідовний порт UART (*Open Serial Monitor*).

## 5 МЕТОДИЧНІ РЕКОМЕНДАЦІЇ ЩОДО ТРАЄКТОРІЇ НАВЧАННЯ

Для досягнення максимальної ефективності опанування освітнього компонента здобувачам рекомендується дотримуватися наступного послідовного алгоритму:
1. **Опрацювання теоретичного базису.** Ознайомлення з темами лекцій та виконання завдань для самостійної роботи (`index-sr.md`).
2. **Алгоритмічний та аналітичний розрахунок.** Виконання практичних занять (`pz-1.md` – `pz-7.md`), розрахунок асимптотичної складності $T(n)$, оцінка кількості операцій $K_{сер}$ та функції трудомісткості $\Psi$.
3. **Програмно-апаратна реалізація.** Виконання лабораторних робіт (`lab-1.md` – `lab-7.md`) у симуляторі SimulIDE, середовищах Node-RED, Arduino IDE та Docker.
4. **Виконання розрахунково-графічної роботи.** Комплексна системна розробка розподіленої КФС згідно з індивідуальним завданням (`index-rgr.md`).
5. **Підсумковий контроль.** Самоперевірка за банком тестових запитань та розв'язання практичних екзаменаційних задач (`quest.md`).
